# Calculadora de Média Escolar em Python

Este projeto foi desenvolvido como atividade prática para demonstrar lógica de programação em Python e boas práticas de documentação utilizando Markdown.

## 📋 Sobre o Projeto

O arquivo `script.py` consiste em um programa de linha de comando (CLI) que solicita o nome de um aluno e três notas bimestrais. Com base nesses dados, o sistema calcula a média aritmética e exibe a situação final do estudante:

* **Aprovado(a):** Média maior ou igual a `7.0`
* **Em Recuperação:** Média entre `5.0` e `6.9`
* **Reprovado(a):** Média abaixo de `5.0`

## 🛠️ Tecnologias Utilizadas

* [Python 3](https://python.org) (Bibliotecas nativas, sem necessidade de instalações externas)

## 🚀 Como Executar o Código

1. Certifique-se de ter o **Python 3** instalado em sua máquina.
2. Clone este repositório ou baixe o arquivo `script.py`.
3. Abra o terminal (ou prompt de comando) na pasta onde o arquivo foi salvo.
4. Execute o seguinte comando:

```bash
python script.py
```

*(Nota: Em alguns sistemas Linux ou macOS, pode ser necessário utilizar `python3 script.py`).*

## 💻 Exemplo de Uso

```text
=== Calculadora de Média Escolar ===
Digite o nome do aluno: Maria Silva
Digite a primeira nota (0 a 10): 8.5
Digite a segunda nota (0 a 10): 7.0
Digite a terceira nota (0 a 10): 9.0

Aluno: Maria Silva
Média final: 8.17

```
